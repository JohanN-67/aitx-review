# aitx-review

**Article Data Viewer** for the Systematic Review.

## Web Application

This repository contains the data extraction pipeline and the visualization site for the systematic review. The site is built to visualize extracted data, generated reports, and summaries.

A live version of the site is available via GitHub Pages:
🔗 [**View the Site Here**](https://JohanN-67.github.io/aitx-review/)

*(Note: Depending on your GitHub Pages configuration, you may need to access it at [`https://JohanN-67.github.io/aitx-review/docs/`](https://JohanN-67.github.io/aitx-review/docs/) if Pages is not explicitly set to serve from the `/docs` folder.)*
